## Customer Segmentation Using Clustering Algorithms

This project performs **customer segmentation** using **unsupervised machine learning** techniques on a dataset containing customer demographics and behavior such as **Age, Annual Income, and Spending Score**.

The goal is to group customers into meaningful clusters to help businesses understand different customer types and design targeted marketing strategies.


## 📌 Problem Statement

Given customer data, apply clustering algorithms to:
- Discover natural groupings in customers
- Visualize and interpret clusters
- Provide business insights based on customer segments

---

## 🧠 Algorithms Used

- K-Means Clustering
- Hierarchical Clustering
- DBSCAN (optional comparison)

---

## ⚙️ Steps Performed

1. **Data Preprocessing**
   - Handling missing values
   - Feature scaling using StandardScaler

2. **Exploratory Data Analysis (EDA)**
   - Distribution plots
   - Correlation analysis

3. **Finding Optimal Clusters**
   - Elbow Method
   - Silhouette Score

4. **Clustering Implementation**
   - Applying K-Means and Hierarchical clustering

5. **Visualization**
   - 2D/3D scatter plots of clusters

6. **Business Insights**
   - Understanding customer groups for marketing strategies

---

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📊 Dataset Features

- Age
- Annual Income (k$)
- Spending Score (1-100)

---

## 📈 Results

Customers were successfully divided into distinct segments such as:
- High income, high spending customers
- Low income, high spending customers
- Moderate income, low spending customers, etc.

These clusters help businesses plan personalized marketing and customer engagement strategies.
